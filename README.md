# student-registration
This project allows users to type a message with a maximum limit of 200 characters. It displays the number of characters typed and remaining in real time, includes a progress bar, shows a warning at the character limit, and provides a clear button to reset the message. Created as a beginner-friendly JavaScript DOM project.

About the Project

The Student Registration Form is a simple and user-friendly web project created using HTML, CSS, and JavaScript. It allows users to enter their name, email address, and password. The form includes real-time validation to check whether the required fields are filled correctly before enabling the registration button.

Features

- Simple and clean user interface.
- Name validation to ensure the field is not empty.
- Email validation to check the email format.
- Password validation with a minimum length of 6 characters.
- Real-time error messages.
- Submit button enabled only when all fields are valid.
- Success message after form submission.

Technologies Used

- HTML5
- CSS3
- JavaScript

How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open "index.html" using Live Server.
4. Enter your details and test the validation.
